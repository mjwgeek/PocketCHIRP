# PocketCHIRP Community Driver Catalog

This directory is the source of truth for PocketCHIRP's optional community-driver catalog.

- `community-drivers.json` contains **approved** entries which PocketCHIRP may offer to users.
- `candidates.json` is generated by GitHub Actions and is **review-only**.
- `sources.json` controls which repositories and GitHub searches the discovery job watches.

## Security model

Discovery never promotes or installs executable Python automatically. A candidate must be manually reviewed before it is copied into `community-drivers.json`. Approved entries should include the exact upstream download URL and SHA-256 of the reviewed file. PocketCHIRP should verify the SHA-256 before loading or installing a community driver.

## Catalog URL

PocketCHIRP can fetch the approved catalog from:

`https://raw.githubusercontent.com/mjwgeek/PocketCHIRP/main/community/community-drivers.json`

## Discovery

The workflow `.github/workflows/discover-community-drivers.yml` runs weekly and can also be started manually from the GitHub Actions page. It scans configured open CHIRP pull requests and GitHub repository searches for likely CHIRP driver Python files, fingerprints them, extracts visible vendor/model metadata, and refreshes `candidates.json`.

To suppress a known unwanted result, add its repository to `ignoredRepositories`, or its `owner/repo#PR` key to `ignoredPullRequests` in `sources.json`.
